# Tayyibat System | طيبات النظام

نسخة مُحدّثة من التطبيق العربي لإدارة المهام والتقدم الشخصي، مع نظام رتب أسبوعي وتحديات تكيفية. الواجهة باتجاه RTL، والهوية البصرية مبنية على درجات كحلية مع علامات رتبة أصلية بالأزرق والبنفسجي والذهبي.

## التشغيل

1. فك حزمة المصدر أو افتح مجلد المشروع.
2. شغّل خادم ملفات محليًا من داخل المجلد:

   ```bash
   python3 -m http.server 8000
   ```

3. افتح `http://localhost:8000` في المتصفح. استخدم `localhost` أو HTTPS؛ فتح `index.html` مباشرة عبر `file://` لا يتيح تثبيت PWA أو التخزين دون اتصال في معظم المتصفحات.
4. على متصفح يدعم التثبيت، استخدم قائمة المتصفح لاختيار **Install app / Add to Home screen**.

المعاينة المؤقتة في بيئة التطوير: https://8765-ipe1xskw18sllp5x9rmxz-922cb061.sg2.manus.computer/

## ما الذي أُضيف؟

- لوحة مرتبة تشمل **E → D → C → B → A → S → SS → SSS → SSS+ → MONARCH**، مع علامة لكل رتبة وتقدم للأسبوع وللرتبة التالية.
- خبرة XP ومستوى دائم لا ينخفضان، مع شريط خبرة إلى المستوى التالي ومنع تكرار XP عند إلغاء إكمال المهمة ثم إكمالها ثانية.
- أولويات وصعوبة ووقت تقديري لكل مهمة، وتحديات اختيارية تراعي الوقت المتاح ومستوى النظام.
- تعديل أوزان القطاعات ومكونات الدرجة وحدود الرتب؛ التقارير الأسبوعية المقفلة تحتفظ بالقواعد التي حُسبت بها.
- ملف تقدم دائم وإنجازات وسجل أسبوعي وتوصيات للتطوير.
- إلغاء يحفظ المهمة في السجل دون احتسابها فشلًا، وإعادة الجدولة تحفظ أصل المهمة وسلسلتها وتُقيّم محاولات العودة دون تكرار XP.
- أيقونات تثبيت أصلية بثلاثة أحجام، وتخزين PWA للإتاحة دون اتصال بعد الزيارة الأولى.

## البيانات والنسخ الاحتياطي

تُحفظ المهام والإعدادات في `localStorage` على **هذا المتصفح والجهاز فقط**؛ لا يرسل التطبيق البيانات إلى خادم. صدّر نسخة JSON من الإعدادات داخل التطبيق بانتظام، واحفظها في مكان آمن. الاستيراد يدمج العناصر غير الموجودة ويتجاوز المعرّفات المكررة بدل استبدال البيانات الحالية. لا تمسح بيانات المتصفح أو تخزين الموقع قبل تصدير نسخة.
